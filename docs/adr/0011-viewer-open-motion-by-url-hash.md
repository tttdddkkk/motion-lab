# 0011: ビューアは URL の `#<id>` で最初に開くモーションを指定できるようにする

- 状態: 採用
- 日付: 2026-11-14

## 背景

PR のプレビュー（[ADR 0010](0010-netlify-deploy-preview.md)）はライブラリ全体を配信する。モーションが増えると、PR で足した・直したモーションを一覧から探す手間が増える。ビューアは常に先頭のモーションを開いていた。

## 決定

- `index.html` が起動時に `location.hash` を読み、一致する `MOTIONS` の `id` があればそのモーションを最初に開く。一致しなければ先頭を開く
- モーションを選ぶたびに `history.replaceState` で `#<id>` を更新し、そのまま URL を共有できるようにする
- PR 本文には「プレビューURL + `#<id>`」を書く（CLAUDE.md の報告の形式）

## 検討した他の案

- PR で変更したモーションだけを配信する: ビルド時の切り出しが要り、ビューアと Storybook が `MOTIONS` を1か所で共有する構成（ADR 0002）と衝突しやすい。デプロイのビルドはファイルのコピーだけで軽く、速度面の利点も小さい。件数が増えて探しにくくなったら再検討する
- PR 本文で「一覧の○番目」と案内する: 件数が増えると探す手間が残る

## 結果

- 確認してほしいモーションを URL で直接開ける。ビューアの他の動作は変わらない
- 一覧には全件が残る
- 将来、変更分だけの配信に切り替えても、この URL はそのまま使える
