# 0008: 流れる文字のモーションは、映像と重ならない別枠で作る

- 状態: 採用
- 日付: 2026-11-13

## 背景

文字が横に流れ、シークバーで進めたり戻したりできるモーションを追加したい。似た表現（動画上にコメントを流す）には、ドワンゴが FC2 との訴訟で権利行使した特許が2件ある。2025-03-03 の最高裁判決でドワンゴの勝訴が確定している。

| 特許 | 請求項1の主な要素 | 満了見込み |
| --- | --- | --- |
| 4734471（表示装置、コメント表示方法、及びプログラム） | 動画を第1の表示欄で再生する。動画の経過時間にひもづいたコメントを、その再生時間に表示する。コメントの表示欄は一部が動画の欄と重なり、一部が外にはみ出していて、はみ出した部分にコメントを表示する | 2026-12-11 |
| 6526304（コメント配信システム） | サーバーと複数の端末。視聴者が投稿したコメントを、再生時間に合わせて動画上で横に流す。コメント同士の重なりを判定し、重ならない位置に調整する | 2027-03-02 |

- 満了見込みと権利の状態は Google Patents の推定（2026-11-13 確認）。特許庁の登録原簿では確認していない
- 調べたのは訴訟になった上記2件だけで、ほかの関連特許の有無は調べていない
- 以下の判断は請求項との比較による推測で、法的な判断ではない

## 決定

次の構成で作る。

- 流れる文字の枠は、映像（動画・静画）の横または下に置き、映像と重ねない。映像の内側にも置かない
- 文字は枠の中で横に流す
- 流す文字はデモ用の固定テキストにする。投稿の仕組みやサーバーは作らない
- 文字の行は事前に決めておく。重なりを判定して自動で避ける処理は入れない
- 見た目は特定のサービス・配信プラットフォーム・配信者の画面に寄せない。サービス名をデモ名や説明に使わない

この構成では、4734471 の「表示欄の一部重なりとはみ出し」と、6526304 の「動画上に表示」「サーバー」「投稿」「重なりの判定と調整」を満たさない（推測。確信度: 中）。

## 検討した他の案

- 映像に重ねて流す（境界をまたぐ枠を含む）: 4734471 の請求項に近づく。必要になった場合は、両特許の満了（2027-03-02 以降）を確認してから見直す

## 結果

- 均等論でどう扱われるかは判断できていない
- 映像への重ね合わせ、投稿の仕組み、重なりの自動回避を足す変更は、この ADR を見直してから行う
- 仕事でこのモーションを使う場合は、弁理士への確認を推奨する
