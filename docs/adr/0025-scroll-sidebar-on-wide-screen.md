# 0025: 広い画面では、サイドバーを画面の高さに固定し、中だけをスクロールする

- 状態: 採用
- 日付: 2026-11-24

## 背景

広い画面（821px 以上）では、サイドバー（`aside`）が一覧の長さだけ縦に伸び、ページ全体と一緒にスクロールしていた。モーションが増えて一覧が画面より長くなると、下のほうのモーションを選ぶにはページごとスクロールする必要があり、そのあいだプレビューが画面の外に出る。ADR 0022 では、広い画面の見た目は変えないとしていた。

## 決定

- 広い画面では、`aside` を `position: sticky; top: 0; height: 100vh; overflow-y: auto` にする。一覧はサイドバーの中でスクロールし、プレビューとコードはページ側でスクロールする
- `overscroll-behavior: contain` で、サイドバーを端まで送ったときにページがつられて動かないようにする
- スマホ幅（820px 以下）は ADR 0022 のまま変えない

## 検討した他の案

- 一覧（`#list`）だけをスクロールさせる: ブランド・モード切り替え・タグは残せるが、差分比較の一覧（`#cmp-nav`）にも同じ指定が要り、高さの計算が表示の切り替えごとに変わる。サイドバー全体なら1か所で済む
- プレビュー側を固定する: プレビューの下にあるコードが長いと、コードを読むためのスクロールと競合する

## 結果

- 一覧のどこを選んでも、プレビューが画面内に残る
- サイドバーとページの 2 か所にスクロールができる。広い画面ではマウスの位置で対象が決まるため、スマホ幅で見送った理由（ADR 0022: 狭い画面での 2 層のスクロール）は当てはまらないと判断した
- `tests/viewer.test.js` に、サイドバーの中だけをスクロールできることと、ページを送ってもサイドバーが残ることを確かめるテストを置いた
