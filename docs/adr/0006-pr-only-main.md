# 0006: main への直接 push を禁止し、PR と CI 成功を必須にする

- 状態: 採用
- 日付: 2026-11-12

## 背景

main への push はそのまま GitHub Pages に公開される。それまでは main に直接 push していた。

## 決定

- GitHub のルールセット `protect-main` を main に設定する。管理者も例外にしない
  - PR を必須にする（承認者は0人。1人運用で自分の PR を承認できないため）
  - CI の `test` ジョブ成功を必須にする
  - 強制 push と削除を禁止する
- マージ済みブランチを自動削除する（`delete_branch_on_merge`）
- CLAUDE.md に「ブランチを切って PR にする」と書く

## 検討した他の案

- CLAUDE.md の記述だけで運用する: 人間の push は止められず、エージェントも指示を外れる可能性がある

## 結果

- 小さな変更でも PR と CI 通過が必要になる
- 対象はこのリポジトリだけ。他のリポジトリには広げていない
