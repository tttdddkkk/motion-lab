# 0003: テストは当面、振る舞いテストだけにする

- 状態: 採用
- 日付: 2026-11-12

## 背景

モーションの不具合を検出したいが、アニメーションのスクリーンショットは途中の状態を写すため、見た目の差分テストは結果が安定しにくい。

## 決定

各ストーリーの `play` 関数で、通常時と「動きを減らす」時の両方について次を確かめる。

- 再生が完了する
- 実行中のアニメーションやリップル要素が残らない
- 「動きを減らす」時は transform と clip-path を使わない
- ボタンをクリックするとアニメーションが始まる

## 検討した他の案

- 見た目の差分テスト（Chromatic など）: アニメーションの停止・固定が必要で、外部サービスの利用も判断が要る。今回は見送り

## 結果

- 見た目の崩れは自動では検出できない
- テストが失敗を検出できることは、わざと壊して確認した（2026-11-12）
