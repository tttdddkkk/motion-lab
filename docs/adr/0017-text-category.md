# 0017: 「テキスト」カテゴリを作り、1つの文章の見せ方を集める

- 状態: 採用
- 日付: 2026-11-15

## 背景

コメント（他者の短い発言が並ぶ・流れる）や通知とは別に、「1つの文章をどう見せるか」の表現（字幕、ティッカー、歌詞の追従表示など）を集めたい。#13（ADR 0014）では、件数が増えるまでテキストのカテゴリは作らないとしていた。

## 決定

- ビューアの `CATS` に「テキスト」（`text`）を足す
- 範囲は、1つの文章（または1組の文章）の見せ方。他者の発言が並ぶものはコメント、システムからの知らせは通知に入れる
- 最初の3件は、軸の違うものにする。並べ方は「現れる → 流れる → 追従する」
  - `typewriter`（字幕: 1文字ずつ現れる）
  - `ticker`（ティッカー帯: 1行の帯の中を途切れずループして流れる）
  - `sync-highlight`（同期ハイライト: 時刻に合わせて今の行が明るくなり、その行を中央へ運ぶ。シークできる）
- ティッカーは横に流れる文字だが、映像に重ねない1行の帯で、他者の投稿（コメント）でもない。ADR 0008 の対象外とする。固定テキストで、特定のサービスの見た目には寄せない点は同じ
- すべて「動きを減らす」版（transform と clip-path を使わない）を用意する

## 検討した他の案

- コメントに入れる: コメントは複数の発言が並ぶ・流れる表現で、1つの文章の見せ方とは軸が違う
- 件数が増えるまで作らない（ADR 0014 の時点の判断）: 3件そろい、軸も分かれたため作る

## 結果

- テキストは3件から始める
- #13（ADR 0014）の「テキストのカテゴリはまだ作らない」は、この ADR で更新する
