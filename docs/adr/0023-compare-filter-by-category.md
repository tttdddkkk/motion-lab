# 0023: 差分比較の絞り込みを、印象ワードからカテゴリ（セクション）に変える

- 状態: 採用
- 日付: 2026-11-20

## 背景

差分比較の絞り込みは、印象ワード（`tags`）のチップだった。ワードの種類が多く、チップが並びすぎて目的の比較にたどり着きにくかった。また、同じワードが別のセクションにまたがるため、絞り込んでも無関係な比較が混ざった。

## 決定

- 絞り込みは `SECTIONS`（ボタン押下 / 画面遷移 / 口頭で混同しやすいペア / 通知）のチップにする。「すべて」で解除する
- 印象ワードはカードの表示だけに残す（データの `tags` は変えない）
- 使われなくなった `ALL_TAGS` は削除した

## 検討した他の案

- 印象ワードを残して並べる: チップが多すぎる問題が残る
- グループ（速度差・イージング差など）単位で絞る: 項目が多く、チップが増える

## 結果

- 4 つのチップで目的のセクションに絞れる
- 印象ワードでの横断検索はできなくなった。必要になったら別の UI で足す
