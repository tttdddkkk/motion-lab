# 0023: 効果を重ねて動きを作る「カスタマイズ」ビューを、MOTIONS・差分比較とは別のデータで持つ

- 状態: 採用
- 日付: 2026-11-20

## 背景

「モーション」は完成した動きを見せ、「差分比較」は1つの軸だけを変えた並びで認識を合わせる。どちらも、用意された動きを選ぶ道具で、自分で動きを組み立てることはできない。

認識合わせでは「フェードしながら少し上がって、ピントが合う感じ」のように、複数の効果を重ねた動きを指したい場面が多い。重ねた結果を、ID と数値（時間・遅れ・イージング・量）で言い表し、そのまま共有・コピーできるようにしたい。

## 決定

- ビューアに「カスタマイズ」を足す（`index.html` の表示切り替え、URL は `#custom` / `#custom=<組み合わせ>`）。データとロジックは `motions/custom.js`、描画は `motions/custom-ui.js`、スタイルは `motions/custom.css`
- 部品は「小さな効果」（フェード・縦／横スライド・拡大縮小・回転・ぼかし）。1つの要素に重ねて1つの動きにする。効果ごとに 時間・遅れ・イージング・量 を持つ。出発点として、ID・印象ワード・使いどころ付きの組み合わせ（`PRESETS`）を置く
- 重ね方: transform の効果は WAAPI の `composite: 'add'` で合成する。opacity と filter は取り合うので、同じ効果は1回までにする。`composite` は Baseline Widely available（2022年9月〜、MDN で確認）
- 出力は差分比較と同じ考え方で、表示・再生・コピーを同じ `layers` から作る。コピーは WAAPI コードと JSON。URL の `#custom=効果,時間,遅れ,easing,量;…` で組み合わせを共有できる。壊れた値は捨て、例外にしない
- 差分比較との共有: トラックの再生と「動きを減らす」設定の扱いは `motions/player.js` に切り出し、両方が使う（ADR 0019。重複させない）。「動きを減らす」設定のときは差分比較と同じく再生を止めて知らせる（ADR 0012）
- データの整合は `tests/custom.test.js`（DOM なし）、画面操作は `tests/viewer.test.js` で検査する

## 検討した他の案

- 既存の `MOTIONS` 同士を組み合わせる: 完成した動きは内部が不透明で（`setup` が DOM を作る）、同じ要素に重ねられない。値も調整できない
- ドラッグ操作のタイムライン: スマホ幅での操作と検証が難しく、工数も大きい。数値スライダーと、読み取り専用の棒で足りる
- 差分比較に組み込む: 比較は「基準から1軸だけ変える」ことが前提で、自由に重ねる用途と合わない
- 外部のアニメーションライブラリ: ビューアは外部ライブラリを前提にしない（`docs/philosophy.md`）。WAAPI で足りる

## 結果

- 効果の追加は `EFFECTS` へのデータ追加だけで済む（`property` が transform なら自動で重ねられる）
- 同じ効果を2回使えない。同じ種類の動きを時間差で2回かけたい場合は、現状できない
- 「出る」方向（退場）の効果は未対応。入ってくる動きだけを扱う
- Safari / iOS での見た目は、実機では未確認（Chromium のみ確認）
