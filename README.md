# Motion Lab

自分用のモーションライブラリ（ボタンエフェクト・画面遷移）。

- 技術: 素の HTML / CSS / WAAPI。外部依存・ビルド工程なし
- 方針: すべてオリジナルのデモとコードで構成する

## 使い方

- `index.html` をブラウザで開く
- モーションを追加するときは、`index.html` 内の `MOTIONS` 配列にオブジェクトを1つ足す（`id / cat / name / feel / use / ms / easing / desc / setup / code{css, waapi, reduced}`）
